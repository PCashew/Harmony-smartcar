# STM32 高精度运动控制

本工程运行在 QST 双板小车的 STM32F103 上，与 Hi3861 的“16_高精度桌面安全导航”配套使用。它不再按固定时间猜测距离和角度，而是用左右轮编码器闭环控制。

## 已实现

- 10 ms 双轮速度 PI 控制。
- 直行时使用本次直行独立的累计编码器误差交叉纠偏，减小两轮摩擦系数不同造成的跑偏。转弯、后退或轨迹回放完成后会重建直行零点，不会把上一动作的一正一负编码器累计值带入直行校正。
- 指定毫米数前进/后退，接近目标时自动减速。
- 指定 0.1° 单位的原地转向，左右轮分别到位后连续稳定 8 个周期才报告完成。
- 串口帧含双帧头、序号、异或校验和帧尾，STM32 返回接收/完成/错误状态。
- 连续行驶指令超过 0.5 秒未刷新时自动停车；位置动作超过 15 秒自动停车。
- 板载前后 WS2812 灯随动作切换：前进前灯白色、倒车后灯红色、左转左侧黄色、右转右侧黄色；停车时前后灯红色。
- 每 100 ms 保存一段左右轮真实编码器增量，环形缓冲最近约 5 秒。收到“原路退回”命令后，倒序并反向回放轮迹，而不是按时间盲倒。

## 硬件与串口

- 左编码器：TIM2，PA0/PA1。
- 右编码器：TIM3，PA6/PA7。
- 电机 PWM：TIM4。
- STM32 USART1：PA9 TX、PA10 RX，115200 8N1。
- Hi3861 GPIO11 TX 接 STM32 PA10；Hi3861 GPIO12 RX 接 STM32 PA9；两板必须共地。

用 Keil 打开 `USER/Template.uvprojx`，编译目标为 `PrecisionMotion`。本工程已用 ARMCC 5.06 update 6 验证为 0 error、0 warning。


## 高精度标定（必须做）

在 `QST_HARDWARE/SYSTEM_CONTROL/control_system.h` 顶部调整：

```c
#define CAR_WHEEL_DIAMETER_X100_MM   6500L
#define CAR_EFFECTIVE_TRACK_X100_MM  13500L
```

数值单位是 0.01 mm。默认轮径 65.00 mm、有效轮距 135.00 mm 只是安全的初始值，不代表每台实车。

1. 直线标定：让小车执行 500 mm，测量实际距离 `L实际`，将轮径改为 `旧轮径 × L实际 / 500`。
2. 转角标定：连续执行 4 次 90°，测量实际总角度 `A实际`，将有效轮距改为 `旧轮距 × 360 / A实际`。
3. 重复一次，直到 500 mm 距离和 360° 累计角度满足要求。

“有效轮距”包含轮胎压缩、地面摩擦和原地转向滑移的综合影响，不应只用尺量机械轮距。没有陀螺仪时，编码器能显著提高重复精度，但无法感知轮胎打滑；更换桌面材质后应重新检查标定。
