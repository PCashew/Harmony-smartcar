# Hi3861 高精度桌面安全导航

本工程运行在 Hi3861 上，配套 `STM32/8_高精度运动控制`。它使用两个前置 TCRT 红外传感器识别桌面/悬空状态，检测到桌沿后先退出危险区，再用舵机带动 HC-SR04 扫描左、中、右三个方向，选择有足够空间且没有近距离障碍物的一侧，最后让 STM32 按编码器完成精确转向。

## 状态流程

1. 上电立即连续发送停车指令。
2. 小车放在桌面中央静止 1 秒，自动学习左右红外传感器的“桌面电平”。信号不稳定时拒绝启动。
3. 倒计时 3 秒后，先完成左前、正前、右前三个方向的超声波检查，再以 95 mm/s 低速直行；独立导航任务每 20 ms 检查红外。
4. 巡航超声波任务以约 1.2 秒一次完整往返的低频节奏持续轮询“左前→正前→右前→正前”，每到一个方向先等待舵机稳定再测距。任一方向在 32 cm 内发现障碍物都会停车，再进行完整的左/中/右多次测距，并向较安全的一侧闭环转向 90°。转弯后必须重新检查三个前方扇区才允许起步；随后两个完整扫描周期内始终保留正前方急停，只暂时屏蔽斜前方重复触发，避免刚绕开的障碍仍留在侧向声束中而造成连续原地转向。
5. 如果左右都不足 25 cm，STM32 倒序回放最近保存的编码器轮迹，每次原路退回最多 80 mm，然后重新扫描；最多尝试两次，仍无安全方向就保持停车。
6. 第一帧可疑红外信号立即停车；连续 3 帧确认才判定桌沿，避免单次干扰。
7. 每次按编码器后退 30 mm，并连续确认两个探头都回到桌面；最多后退 150 mm，仍不安全则锁定停车。
8. 巡航扫描的舵机低电平阶段会主动让出 CPU，因此扫斜前方时红外防跌落任务仍会运行；车辆静止后，超声波左/中/右各采样多次并取中值。单侧少于 25 cm 或测距无效时不选该侧。
9. 舵机 PWM 周期仍为标准的约 20 ms（50 Hz）；当前降低的是摇头扫描节奏，每个方向发送 10 个控制脉冲并额外稳定约 70 ms，以减少 SG90 抖动和超声波误测。
9. 左探头遇边优先右转，右探头遇边优先左转；两侧同时遇边则选择测得空间更大的一侧。
10. STM32 执行 90.0° 编码器闭环转向并返回完成状态，之后恢复巡航。

任何传感器读取失败、串口动作超时、退回桌面失败或左右两侧都不安全，程序都会保持停车，不会盲目前进。

## 引脚

| 模块 | Hi3861 引脚 |
|---|---:|
| 左 TCRT | GPIO13 |
| 右 TCRT | GPIO14 |
| SG90 信号 | GPIO2 |
| HC-SR04 Trig | GPIO7 |
| HC-SR04 Echo | GPIO8 |
| UART2 TX/RX | GPIO11/GPIO12 |

HC-SR04 Echo 通常为 5 V，必须确认小车扩展板已有分压/电平转换；若是直接连接 Hi3861，不能把 5 V 回波直接送入 3.3 V GPIO。

## 放入 OpenHarmony 并编译

复制为：

```text
applications/sample/wifi-iot/app/github_16_PrecisionTableNav
```

将 `applications/sample/wifi-iot/app/BUILD.gn` 的 `features` 设为：

```gn
features = [
    "github_16_PrecisionTableNav:PrecisionTableNav",
]
```

在源码根目录执行：

```bash
python build.py wifiiot
```

烧录 `out/wifiiot/Hi3861_wifiiot_app_allinone.bin`。

## 首次测试（不要省略）

1. 先烧录 STM32 固件，再烧录 Hi3861 固件。
2. 把整车架高，让轮子悬空；红外探头对着一块与目标桌面相同的纸板，上电完成自动校准。
3. 移开左/右纸板模拟悬空，确认对应动作方向正确。方向相反时不要落地测试。
4. 在地面低速验证后退距离和 90° 转角，并按 STM32 README 完成轮径与有效轮距标定。
5. 最后才在桌面测试，第一次在桌沿放挡板并准备随时断电。

数字红外只能在桌面和悬空能产生稳定不同电平时工作。强阳光、镜面/纯黑桌面、探头太高或比较器阈值不合适都会导致失效。超声波只负责选择转向空间，不能代替朝下的红外防跌落。HC-SR04 对很软、很薄、吸声或与声束夹角过大的物体仍可能回波很弱，三方向扫描能显著缩小盲区，但不能把超声波变成全角度传感器。

轨迹回放只能返回刚刚由车轮实际走过的路径，不能发现回放期间突然出现在车尾的新障碍或新的桌沿。没有后置向下传感器时它是风险降低措施，不等同于后方安全检测。
