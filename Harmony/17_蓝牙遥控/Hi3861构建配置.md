# Hi3861 蓝牙遥控构建配置

在编译本工程前，编辑 SDK 文件：

`vendor/hisi/hi3861/hi3861/build/config/usr_config.mk`

必须保持：

```text
# CONFIG_AT_SUPPORT is not set
CONFIG_UART2_SUPPORT=y
```

- 关闭 AT 服务，避免它与 JDY-16 同时读取 UART1。
- 开启 UART2，使 GPIO11/GPIO12 能与 STM32 通信。

未使用以上配置时，实机会输出 `Failed to init uart! Err code = -1`，随后蓝牙控制任务不会启动。
