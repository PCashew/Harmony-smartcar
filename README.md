# 学习记录与项目代码

本仓库用于记录个人学习过程、课程实验、编程实践以及项目代码。

通过 Git 对学习过程和代码进行版本管理，记录不同阶段的学习内容和项目成果。

---

## 📁 仓库目录

```text
.
├── README.md
│
├── 学习日志/
│   ├── 2026-08-25.md
│   └── ...
│
├── 项目/
│   ├── 智能小车/
│   └── ...
│
└── .gitignore
```

### 学习日志

用于记录每日学习内容、实验过程、遇到的问题以及学习总结。

目前已有：

* [2026-08-25 学习日志](学习日志/2026-08-25.md)

后续按照日期继续添加：

```text

2026-08-27.md
2026-08-28.md
...
```

---

## 💻 项目

用于保存课程实验、个人项目以及编程实践代码。

目前主要涉及：

* C / C++
* 数据结构与算法
* Linux
* 嵌入式开发
* Keil
* STM32
* VS Code
* Git / GitHub

项目按照独立目录进行管理，每个项目可以包含源代码、工程文件以及项目说明。

---

## 🔧 开发环境

主要使用以下开发工具和环境：

| 工具 / 环境 | 用途            |
| ------- | ------------- |
| VS Code | 代码编辑与开发       |
| Keil    | 单片机工程开发       |
| ST-Link | 单片机程序烧录       |
| Linux   | Linux 环境学习与开发 |
| VMware  | Linux 虚拟机运行   |
| Git     | 版本控制          |
| GitHub  | 代码及学习资料管理     |

---

## 📌 仓库说明

本仓库会持续更新。

学习日志按照日期进行记录，项目代码按照项目进行分类，逐步形成完整的学习记录和代码库。

```text
学习
 ↓
实践
 ↓
代码
 ↓
记录
 ↓
版本管理
 ↓
```
