# 2026.8.25 学习日志

## 一、上午学习内容：Keil 与智能小车

### 1. Keil 工程文件

学习在 Keil 中打开已有的单片机工程文件，了解 Keil 工程的基本组成以及工程文件的加载方式。

主要操作：

* 打开已有 Keil 工程。
* 查看工程目录及源代码文件。
* 检查工程配置。
* 对工程进行编译。
* 查看编译结果及错误信息。

### 2. ST-Link 程序烧录

学习使用 ST-Link 将编译后的程序烧录至智能小车的单片机。

基本流程：

```text
Keil 工程
    ↓
编译程序
    ↓
生成目标程序
    ↓
连接 ST-Link
    ↓
下载程序
    ↓
智能小车运行程序
```

通过实际操作，掌握了使用 ST-Link 进行单片机程序下载的基本方法。

### 3. 串口通信

使用串口助手与智能小车进行通信。

实验操作：

```text
串口助手
    ↓
发送 HELLO
    ↓
智能小车接收串口数据
    ↓
执行对应功能
    ↓
实现跑马灯
```

最终成功通过串口助手向智能小车发送 `HELLO`，并使小车成功实现跑马灯功能。

通过该实验，初步掌握了单片机程序从**工程编译、程序烧录、串口通信到硬件运行**的完整流程。

## 二、下午学习内容：Linux Terminal

下午在 Linux 虚拟机中学习 Terminal 的基本使用方法，重点学习 Linux 命令行操作、文件管理以及终端快捷键。

### 1. 文件与目录操作

| 命令            | 功能              |
| ------------- | --------------- |
| `pwd`         | 查看当前工作目录        |
| `ls`          | 查看当前目录内容        |
| `ls -l`       | 以详细格式查看目录内容     |
| `ls -a`       | 查看包括隐藏文件在内的所有文件 |
| `cd 目录名`      | 进入指定目录          |
| `cd ..`       | 返回上一级目录         |
| `cd ~`        | 返回用户主目录         |
| `cd /`        | 进入根目录           |
| `mkdir 目录名`   | 创建目录            |
| `touch 文件名`   | 创建文件            |
| `cp 源文件 目标位置` | 复制文件或目录         |
| `mv 源文件 目标位置` | 移动或重命名文件        |
| `rm 文件名`      | 删除文件            |
| `rm -r 目录名`   | 删除目录及其内容        |

### 2. 文件内容查看与文本处理

| 命令                  | 功能          |
| ------------------- | ----------- |
| `cat 文件名`           | 查看文件内容      |
| `less 文件名`          | 分页查看文件      |
| `head 文件名`          | 查看文件开头内容    |
| `tail 文件名`          | 查看文件末尾内容    |
| `grep 关键词 文件名`      | 搜索指定文本      |
| `find 路径 -name 文件名` | 查找指定文件      |
| `wc 文件名`            | 统计文件行数、单词数等 |
| `sort 文件名`          | 对文本内容进行排序   |
| `diff 文件1 文件2`      | 比较两个文件的差异   |

### 3. 系统及进程操作

| 命令         | 功能          |
| ---------- | ----------- |
| `clear`    | 清空终端内容      |
| `history`  | 查看历史命令      |
| `whoami`   | 查看当前用户      |
| `uname -a` | 查看系统信息      |
| `date`     | 查看当前日期和时间   |
| `ps`       | 查看当前进程      |
| `top`      | 查看系统运行状态及进程 |
| `kill PID` | 结束指定进程      |
| `exit`     | 退出当前终端      |

### 4. 帮助命令

| 命令          | 功能          |
| ----------- | ----------- |
| `man 命令`    | 查看命令的详细帮助文档 |
| `命令 --help` | 查看命令的帮助信息   |

例如：

```bash
man ls
```

或者：

```bash
ls --help
```

### 5. 网络与远程操作

| 命令                 | 功能                |
| ------------------ | ----------------- |
| `ping 地址`          | 测试网络连接            |
| `ip addr`          | 查看网络接口及 IP 地址     |
| `ssh 用户名@IP`       | 通过 SSH 远程连接 Linux |
| `scp 文件 用户名@IP:路径` | 在本地和远程主机之间复制文件    |
| `wget 地址`          | 下载网络文件            |
| `curl 地址`          | 发送网络请求            |

### 6. 权限与软件管理

| 命令                | 功能          |
| ----------------- | ----------- |
| `sudo 命令`         | 使用管理员权限执行命令 |
| `chmod`           | 修改文件或目录权限   |
| `chown`           | 修改文件或目录所有者  |
| `apt update`      | 更新软件包列表     |
| `apt install 软件名` | 安装软件        |
| `apt remove 软件名`  | 卸载软件        |

## 三、Linux Terminal 常用快捷键

| 快捷键        | 功能               |
| ---------- | ---------------- |
| `Ctrl + C` | 终止当前正在执行的命令      |
| `Ctrl + Z` | 暂停当前程序           |
| `Ctrl + D` | 退出当前 Shell 或结束输入 |
| `Ctrl + L` | 清空终端屏幕           |
| `Ctrl + A` | 移动到当前命令行开头       |
| `Ctrl + E` | 移动到当前命令行末尾       |
| `Ctrl + U` | 删除光标前的全部内容       |
| `Ctrl + K` | 删除光标后的全部内容       |
| `Ctrl + W` | 删除光标前的一个单词       |
| `Ctrl + R` | 搜索历史命令           |
| `Tab`      | 自动补全命令、文件名或目录名   |
| `↑`        | 查看上一条历史命令        |
| `↓`        | 查看下一条历史命令        |
| `←`        | 向左移动光标           |
| `→`        | 向右移动光标           |
| `Home`     | 移动到命令行开头         |
| `End`      | 移动到命令行末尾         |
